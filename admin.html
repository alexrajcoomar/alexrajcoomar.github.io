    Connection

    This page saves changes by writing to the site's GitHub repository. To do that it needs a token, which you create yourself and paste in here. It is stored only in this browser and is never sent anywhere except to GitHub.

    How to make the token

    1. Sign in to GitHub as the account that owns the site, and open Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Name it something like Site editor and set the expiry you want. When it expires the editor will say so, and you make a new one the same way.
    3. Under Resource owner choose the organisation that owns the site, then under Repository access choose Only select repositories and pick the site's repository.
    4. Under Permissions → Repository permissions set Contents to Read and write. Leave everything else alone. That one permission is all this needs.
    5. Generate it, copy it, and paste it below. GitHub shows it once.

    A token is a password. It is held for this browser tab only and is forgotten when the tab closes, so expect to paste it again next time you sit down to publish. Do not paste it into anything else, and do not use this editor on a shared computer. Forget the token clears it immediately.
